# Samples

These are the only recordings in Tock-8; every other sound is synthesised. Each file here was cut from a recording on
Wikimedia Commons that is in the public domain or released under CC0, so it can be copied, changed and shared freely.
Nothing here needs crediting by law; the list exists so anyone can check where a sound came from.

`tools/make_samples.py` holds the exact cuts. To rebuild, save each source as `renders/raw-<name>.wav` and run it.
Downloaded 2026-11-17.
